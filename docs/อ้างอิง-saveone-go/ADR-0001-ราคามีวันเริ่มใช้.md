# ราคามีวันเริ่มใช้ — วันที่ผ่านไปแล้วไม่ถูกคิดราคาใหม่

ราคาย้ายจากโค้ดไปให้ admin แก้ในหน้าตั้งค่า (23 ก.ย. 2569) เราเลือกให้ราคาทุกชุดมี **วันเริ่มใช้** และรายรับของแต่ละวันคิดด้วยราคาที่มีผลในวันนั้นเสมอ
แทนที่จะเก็บราคาชุดเดียวแล้วคิดใหม่ทั้งหมด เพราะรายรับเดือนที่ปิดไปแล้วถูกรายงานผู้บริหารไปแล้ว ถ้าเปลี่ยนตามจะกระทบยอดจริง และกราฟเทียบเดือน / Benchmark จะเชื่อไม่ได้

ผลที่ตามมา: เก็บราคาเป็นประวัติหลายชุด ไม่ใช่ค่าเดียว · ห้ามมีทางลัดในหน้าเว็บที่แก้ราคาย้อนหลัง
