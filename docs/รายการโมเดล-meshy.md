# รายการโมเดลสั่ง Meshy (แผน Pro 1 เดือน)

> ร่าง 24 ต.ค. · เจ้าของจะสมัคร 1 เดือน ใช้ให้คุ้มที่สุด · เจ้าของแก้/เพิ่ม/ตัดรายการได้เลย
> ตัวเลขราคา/เครดิต จากหน้า meshy.ai/pricing วันที่ 24 ต.ค. — ราคาจริงต่อชิ้นดูในแอปก่อนกดสร้าง

## ข้อเท็จจริงแผน Pro

- ฿325 เดือนแรก → ต่ออัตโนมัติ ฿649/เดือน
- 1,000 เครดิต/เดือน **ไม่สะสม** (หมดเดือนหาย)
- โมเดลมีสี ≈ 30 เครดิต/ชิ้น → **≈ 30 ชิ้น/เดือน** · สั่งซ้ำเพราะไม่สวย = ได้น้อยลง
- ไลเซนส์: เป็นของเรา ใช้เชิงพาณิชย์ได้ · ดาวน์โหลดไม่จำกัด (รวมคลังโมเดลชุมชน)
- ยกเลิกแล้ว โมเดลที่ดาวน์โหลดไว้ใช้ต่อได้

## กฎ

- **แบรนด์จริง (MR.DIY โลตัส ฯลฯ) ไม่สร้างโมเดล** — ใช้ตึกทั่วไป + แปะโลโก้ (`logos/`) เหมือนเดิม
- ตึก: ออกแบบหลายแบบไว้ใช้ซ้ำ ไม่มีป้ายชื่อ ไม่มีตัวหนังสือบนโมเดล
- ทุกชิ้นสั่งแบบ **polycount ต่ำ** (ราว 10k–30k) — ใช้บนเว็บ/มือถือ · ไฟล์หนักไป Claude ลดใน Blender ได้ แต่สีพื้นผิวอาจเพี้ยน
- ขนาดใน Meshy ไม่ตรงของจริง → Claude ย่อ/ขยายใน Blender ตามคอลัมน์ "ขนาดจริง" (`glb(dims=...)`)
- ดาวน์โหลด GLB เก็บใน `models/meshy/` · ⚠️ ต้องเพิ่มใน `build-assets.py` ให้ข้ามโฟลเดอร์นี้ (ไม่งั้น assets.js ฝังทั้งหมด บวมหลาย MB) เหมือน `models/ar`

## ขั้นตอนให้คุ้ม

**ก่อนสมัคร (ไม่เสียเงิน)**
1. เจ้าของดูรายการข้างล่าง แก้/เพิ่ม/ตัด
2. ของที่ตลาดเรามีจริง (หม้อไฟ แท้งน้ำ ซุ้ม รถเข็น) → **ถ่ายรูปของจริงไว้** ใช้ "รูป → 3D" ได้ของหน้าตาตรงตลาดเรากว่าพิมพ์บรรยาย
3. ลองแผนฟรี (100 เครดิต) 2–3 ชิ้น ปรับคำสั่งจนพอใจ · แผนฟรีเป็น CC BY ใช้แค่ทดลอง ไม่เอาขึ้นเว็บ

**ต่อ connector (MCP) ให้ Claude สั่ง Meshy ตรง** — กุญแจ API ต้องแผน Pro ขึ้นไป
- เครื่องพร้อม: Node v20.18 · Claude Code 2.1.310 (เช็ก 24 ต.ค.) · ยังไม่มี meshy ใน `claude mcp list`
- เจ้าของทำเอง (Claude ไม่พิมพ์กุญแจ): สร้างกุญแจใน "แพลตฟอร์มสำหรับนักพัฒนา" (meshy.ai/settings/api → ปุ่ม "เปิดแพลตฟอร์มสำหรับนักพัฒนา" · ย้ายมาที่นี่แล้ว 24 ต.ค.) → เปิด PowerShell **หน้าต่างแยก** (ไม่ใช่ `!` ในแชต กุญแจจะติดในบทสนทนา) แล้วรัน
  `claude mcp add meshy -s user -e MESHY_API_KEY=msy_กุญแจ -- cmd /c npx -y @meshy-ai/meshy-mcp-server`
  (`-s user` = เก็บใน config ผู้ใช้ ไม่เข้า repo · `cmd /c` = Windows ต้องใช้กับ npx)
- เช็ก: `/mcp` ขึ้น meshy ✓ → Claude เรียก `meshy_check_balance` ดูเครดิต
- MCP ทำได้: สร้าง (ข้อความ/รูป → 3D) · กำหนด polycount (`target_polycount`) · ตั้งขนาดจริง · ดาวน์โหลด · **ค้นคลังชุมชนไม่ได้** → คลังชุมชนใช้ Chrome
- ที่มา: https://www.meshy.ai/mcp · https://github.com/meshy-dev/meshy-mcp-server

**เดือนที่สมัคร**
4. วันแรก: ปิดต่ออายุอัตโนมัติก่อน (เช็กว่ายังใช้ได้ถึงสิ้นรอบ)
5. **โหลดของฟรีในคลังชุมชน Meshy ก่อน** (เจ้าของ 24 ต.ค. · Pro โหลดได้ไม่จำกัด ไม่หักเครดิต)
   - ไล่ทุกรายการข้างล่าง มีในคลังแล้ว → โหลด ไม่สร้างเอง · เหลือเครดิตไว้ทำของเฉพาะไทย (รถเข็นไทย หม้อไฟ เก้าอี้แดง น้ำพุม้า คนไทย ตึกที่ออกแบบเอง)
   - ของอื่นที่ใช้ได้ในอนาคตก็โหลดเก็บไว้ด้วย — หมดเดือนแล้วโหลดไม่ได้อีก
   - เช็กไลเซนส์แต่ละชิ้นในหน้าโมเดล · จดชื่อ/ลิงก์/ไลเซนส์ใน `models/meshy/ที่มา.md`
6. สร้างแบบ "ร่าง" (mesh) ก่อน · ทำสีเฉพาะชิ้นที่รูปทรงผ่าน
7. ดาวน์โหลดทุกชิ้นทันทีที่เสร็จ + สำรองนอก repo
8. ก่อนครบเดือน: เครดิตเหลือ → ใช้กับกลุ่ม ง
