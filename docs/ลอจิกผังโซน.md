# ลอจิกผังโซนโคราช

เขียนจากโค้ดจริง 24 ต.ค. 69 · ถ้าโค้ดเปลี่ยน ให้แก้ไฟล์นี้ด้วย

## ไฟล์ไหนทำอะไร

| ไฟล์ | หน้าที่ |
|---|---|
| `ผังโซนโคราช.html` | ผัง 3 มิติ + แผงรายละเอียด + ตรรกะทั้งหมด (CSS + JS ในไฟล์เดียว) |
| `content.js` | **เนื้อหาทั้งหมด** (`window.CONTENT={…}` · เป็น JSON ล้วน) — หน้าแอดมินเขียนไฟล์นี้ |
| `admin/index.html` | หน้าแอดมิน (เปิด `/admin`) |
| `assets.js` | โมเดล/โลโก้/รูปฝังเป็น data URI (สร้างจาก `build-assets.py` · ~5.6 MB) |
| `ผังโซนโคราช-ไฟล์เดียว.html` | ส่งต่อได้ไฟล์เดียว = หน้าหลัก + assets.js + content.js ฝังรวม (สร้างจาก `build-assets.py`) |
| `index.html` | ลิงก์สั้นของ Pages → เด้งไปหน้าผัง (ชื่อไฟล์ไทย) |
| `photos/` | รูปจริง (ย่อ 560 px) · `lot-*.jpg` = ภาพจัดล็อกจาก Blender · `u-*.jpg` = รูปที่อัปผ่านแอดมิน |
| `blender/` | สคริปต์ Blender (ชุดไทย · ภาพจัดล็อก · ภาพ 4K) |

## ลำดับโหลดหน้าผัง

1. `assets.js` → `window.ASSETS` · `A(path)` = data URI ถ้ามี ไม่มีก็คืน path เดิม (โหลดจากโฟลเดอร์)
2. `content.js?t=<นาที>` ผ่าน `document.write` — `?t=` เปลี่ยนทุกนาที หลบแคช 10 นาทีของ GitHub Pages
3. ถ้า URL มี `?preview` → ทับ `CONTENT` ด้วยร่างใน `localStorage['zonemap-draft']` และรวม `pending` (รูปยังไม่อัป) เข้า `ASSETS`
4. สคริปต์หลัก: `ZONES = zones.map(z => ({...groups[z.group], ...z}))` → วาดรายการ/หัวเว็บ → โหลด three.js → `build3()` (พังเมื่อไหร่ = `fallback()` ผังแบน SVG)

⚠️ `build-assets.py` หาบรรทัด `document.write(...content.js...)` และ `<script src="assets.js">` แบบตรงตัว — แก้สองบรรทัดนี้ต้องแก้สคริปต์ด้วย (มี assert กันไว้)

## โครง `content.js`

```
site      หัวเว็บ · firstSteps [[หัวข้อ,รายละเอียด]] · calls [[เบอร์,ใช้สำหรับ]] · office [[หัวข้อ,ข้อมูล]] · footer
kinds     ชื่อหมวด {food, boot, event, park}
season    ป้ายช่วงราคา {low, high}   ← ป้ายเท่านั้น วันที่สลับจริงอยู่ในโค้ด (ดูข้อราคา)
elec      ค่าไฟ (ทุกโซนขาย) · feeNote ข้อความใต้ราคาวันนี้
groups    food / boot = ค่ากลางของกลุ่ม (ไอคอน ราคา วิธีจอง เงื่อนไข คืนเงิน เบอร์ IG หมายเหตุ รูป …)
zones[]   id (ผูกกับรูปบนผัง ZG — ห้ามเปลี่ยน) · group หรือ kind · name · where · ช่องที่ทับของกลุ่มได้
```

- โซนในกลุ่ม: ช่องที่โซนใส่เอง = ทับของกลุ่ม (เช่น ศูนย์อาหาร ทับ `ok/no/noTo/photos/model`)
- `ok`/`no` = `[[อีโมจิ, ป้าย]]` · `no` ว่าง = ไม่มีหัว "ห้ามขาย" · หน้าเว็บวาดวงกลมแดงขีดทับอีโมจิห้ามเอง
- `facts` = `[อีโมจิ, ป้าย, ค่า, เต็มแถว?]` · ไฟฟ้า + พื้นที่ โค้ดต่อท้ายให้เอง
- `tiers` = `[{codes, low:[จ.–พฤ., ศ.–อา.], high:[…]}]`
- `tel` = `[เบอร์ปุ่มใหญ่, เบอร์ที่ 2]` · เบอร์ที่ 2 โชว์เมื่อไม่มี `ig`
- `model` = โมเดลบนการ์ดโฮโลแกรม (`tent` `kiosk` `car` `stage` `park`) — แอดมินไม่แสดงช่องนี้
- เพิ่ม/ลบโซนผ่านแอดมินไม่ได้ (โซนผูกกับรูปบนผัง) — ต้องแก้ `ZG` + `LBL` ในโค้ด แล้วเพิ่มใน `zones`

**ข้อความจากเนื้อหาผ่าน `esc()`/`rt()` ทุกจุด** (กันแท็ก HTML) · `[ข้อความ]` = `<small>` ตัวเล็กสีเทา · ขึ้นบรรทัด = `<br>`
ค่าที่โค้ดคำนวณเอง (พื้นที่ จำนวนล็อก) ส่งเข้า `facts` เป็น `{h: html}` ไม่ผ่าน `rt()`

## ราคา

- ฤดู: **low = 13 เม.ย.–31 ต.ค. · high = 1 พ.ย.–12 เม.ย.** — ตัดสินด้วย `md = เดือน×100+วัน` ช่วง `413–1031` = low (ฮาร์ดโค้ดใน `ผังโซนโคราช.html`)
  ⚠️ ป้าย `season` ใน content.js แก้ผ่านแอดมินได้ แต่**ไม่เปลี่ยนวันสลับจริง** — ตลาดเปลี่ยนช่วงฤดูเมื่อไหร่ ต้องแก้โค้ดด้วย
- สุดสัปดาห์ = ศ. ส. อา. (`getDay()` 5, 6, 0) — ตรงกับเว็บหลัก `isWknd`
- "ราคาวันนี้" = ช่วงต่ำสุด–สูงสุดของทุกแถวราคาในฤดู × วันนี้ · "ทั้งปี" = ต่ำสุด–สูงสุดทุกช่อง
- ราคาบนผัง = **จองผ่านแอป** · จองเคาน์เตอร์ +30 (อาหาร) / +50 (เปิดท้าย) เขียนในวิธีจอง ไม่ได้คำนวณ
- เวลาเครื่องผู้ดู ไม่ได้บังคับเขตเวลาไทย

## ผังและการคำนวณพื้นที่

- พิกัด = พิกัดภาพแผนที่ตลาด `Saveone_Korat_Map (28-8-69).jpg` · y = ทิศใต้ · `ZG[id]` = รูปหลายเหลี่ยมของแต่ละโซน
- มาตราส่วน: ทั้งตลาด (`SITE` + `ANNEX`) = **88 ไร่ = 140,800 ตร.ม.** (ข่าวไทยรัฐ) → `M_PER` เมตรต่อหน่วยผัง (≈ 0.35) · `U` = หน่วยผังต่อเมตร
- พื้นที่โซน = พื้นที่รูปหลายเหลี่ยม × M_PER² ปัดหลักร้อย · 1 ไร่ = 1,600 ตร.ม.
- จำนวนช่อง (`slots`) วางกริดตามขนาดจริง ช่องต้องอยู่ในรูปโซนครบทุกมุม:
  - ลานจอด: ช่อง 2.5 × 5 ม. หันหลังชน 2 แถว + ทางวิ่ง 6 ม.
  - เปิดท้าย: ล็อก 2.4 × 8 ม. (รถ 4.5 + ที่ขาย 3.5) หันหลังชน + ทางเดิน 6 ม.
  - สตรีทฟู้ด: เต็นท์ 3 × 3 ม. ขนาบทางเดิน 4 ม. (ภาพ 3 มิติ — ล็อกจริงคือโต๊ะ 75 × 75 ซม.)
  → ตัวเลขเป็น**ค่าประมาณจากผัง** หน้าเว็บติด "≈" และ "?" ไว้เสมอ
- `BLD` อาคาร · `LBL` ป้ายชื่อโซนบนผัง · `ROOF_LOGO` โลโก้บนหลังคา (`logos/`) · `ROOF_TXT` ป้ายวาดเอง

## 3 มิติ

- three.js r128 (cdnjs) + GLTFLoader (jsdelivr) · กล้องลอยกลางตลาดมองลง ไม่หมุน · แตะโซน = บินเข้า + เปิดการ์ดโฮโลแกรม
- โมเดล: Kenney.nl (CC0) + ชุดไทยจาก Blender (`models/blender/`) · `?thai=0` = ใช้ชุด Kenney แบบเดิม
- โฮโลแกรม = ร้านตัวอย่าง 1 ล็อกหมุนช้าๆ · มือถือ (≤ 860 px) ซ่อนสถิติ/ไอคอนในการ์ด แสดงปุ่ม "ขายอะไรได้ · ราคา · วิธีจอง ↓" แทน
- เปิด WebGL ไม่ได้ = ผังแบน SVG (`buildFlat`)

## ภาพจัดล็อก (Blender)

`blender/lot-guide.py -- all` → `blender/lot-*.png` → แปลงเป็น `photos/lot-*.jpg` ด้วย Python ของเครื่อง (Blender ไม่มี PIL) → `python build-assets.py`
ป้ายใต้ภาพวางที่ % ตามพิกัด x จริง: (กลางกลุ่ม − ขอบซ้ายกรอบ) ÷ กว้างกรอบ
อาหาร กรอบ −0.8…7.45 ม. · เปิดท้ายแนวตั้ง −1…10.2 · แนวนอน −1…19.8 — แก้กรอบในสคริปต์ ต้องแก้ % ใน `dgFood`/`dgBoot` ด้วย

## หน้าแอดมิน (`admin/index.html`)

- ฟอร์มสร้างจากรายการช่อง (`sections()` / `F(type, key, label)`) · ชนิดช่อง: text · area · list · pairs · icons · facts · tiers · photos · tel
- รูป: ย่อในเบราว์เซอร์ (ด้านยาว ≤ 1200 px · JPEG 0.82) · **ชื่อใหม่เสมอ** `photos/u-YYYYMMDD-HHMMSS-xxxx.jpg`
  เพราะ `assets.js` ฝังรูปเก่าไว้ ถ้าใช้ชื่อเดิม หน้าเว็บจะยังเห็นรูปเก่า · รูปที่เอาออกยังอยู่ใน repo (ย้อนได้)
- ร่าง: `localStorage['zonemap-draft']` = `{content, orig, pending}` · เปิดใหม่แล้วฐานตรงกัน → ถามว่าจะใช้ร่างต่อไหม
- 👁 ดูตัวอย่าง = เปิด `../ผังโซนโคราช.html?preview`
- บันทึก = GitHub Git Data API เป็น **1 commit**: blob (รูปใหม่ + content.js) → tree → commit → ย้าย `main`
  ก่อนบันทึกเทียบ sha ของ content.js บน `main` กับตอนโหลด — ต่างกัน = มีคนบันทึกแทรก → ถามก่อนทับ
  commit message = "แก้เนื้อหาผ่านหน้าแอดมิน (ชื่อบัญชี)" + รายการหมวดที่แก้
- เข้าระบบ: กุญแจ GitHub ของแต่ละคน (classic token ติ๊ก `repo`) เก็บใน localStorage/sessionStorage ของเครื่องนั้น · ตรวจ `permissions.push` ก่อนให้แก้
- repo ที่เขียน: อ่านจากที่อยู่หน้าเว็บ (`<owner>.github.io/<repo>/`) · เปิดที่อื่น = `GenZeus-web/saveone-korat-zonemap`
- ไม่มีกุญแจ = "โหมดลอง" แก้ + ดูตัวอย่างได้ บันทึกไม่ได้
- ⚠️ ไฟล์เดียว (`-ไฟล์เดียว.html`) ไม่ตามที่แก้ผ่านแอดมิน จนกว่าจะรัน `build-assets.py` ใหม่

## ทดสอบในเครื่อง

- `python -m http.server 8790` ในโฟลเดอร์นี้ → `http://localhost:8790/ผังโซนโคราช.html` · `/admin`
- เช็คมือถือ: หน้าต่าง Chrome แคบกว่า ~650 px ไม่ได้ → ใส่หน้าใน iframe กว้าง 390 px แล้วดู `scrollWidth` (ต้อง = ความกว้างจอ)
- เช็คว่าแก้ตรรกะแล้วข้อความไม่เปลี่ยน: เทียบ `innerText` ของแผงทุกโซนกับไฟล์ใน `_สำรอง/` (ทำแล้วตอนแยก content.js — ตรงทุกตัวอักษร)
- ไวยากรณ์: ดึงทุก `<script>` ออกมาเป็นไฟล์แล้ว `node --check`
