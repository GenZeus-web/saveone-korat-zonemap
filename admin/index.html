แก้ผังโซนโคราช

แก้ข้อความ · ราคา · ไอคอน · รูป แล้วกดบันทึก เว็บเปลี่ยนใน ~1–2 นาที

เข้าระบบ

ใช้บัญชี GitHub ของตัวเอง ที่เจ้าของ repo เชิญเข้าแล้ว

  1. ล็อกอิน GitHub แล้วเปิด หน้าสร้างกุญแจ (ติ๊ก repo ไว้ให้แล้ว)
  2. ตั้งวันหมดอายุ → กด Generate token → คัดลอกรหัสที่ขึ้นต้น ghp_
  3. วางช่องล่าง (ทำครั้งเดียวต่อเครื่อง)

ไม่ได้ล็อกอินก็ ได้ แต่บันทึกขึ้นเว็บไม่ได้

[ข้อความ] = ตัวเล็กสีเทา · กด Enter ในกล่องใหญ่ = ขึ้นบรรทัดใหม่ · ? = ยังรอยืนยัน · ไอคอนใช้อีโมจิจากแป้นมือถือ
