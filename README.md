# ผังโซนตลาดเซฟวัน โคราช (ร่าง)

หน้าเว็บสำหรับผู้ค้า: แตะโซนบนผัง 3 มิติ ดูว่าขายอะไรได้ ราคา วิธีจอง และรูปจริง · ออกแบบให้มือถือเป็นหลัก

## เปิดดู

- **ไฟล์เดียว:** ดับเบิลคลิก `ผังโซนโคราช-ไฟล์เดียว.html` (ฝังโมเดล/รูปไว้ในไฟล์ · ส่งต่อได้)
- **ตัวแก้:** `python -m http.server 8790` ในโฟลเดอร์นี้ แล้วเปิด `http://localhost:8790/ผังโซนโคราช.html`

## แก้แล้วต้องทำ

1. แก้ `ผังโซนโคราช.html`
2. `python build-assets.py` → สร้าง `assets.js` + `ผังโซนโคราช-ไฟล์เดียว.html` ใหม่

## โครงสร้าง

| ที่ | อะไร |
|---|---|
| `ผังโซนโคราช.html` | หน้าเว็บทั้งหมด (ข้อมูลโซนอยู่บนสุดของ `<script>`) |
| `models/` | โมเดล 3 มิติ (Kenney.nl CC0 + ชุดไทยที่สร้างเองใน `models/blender/`) |
| `logos/` | โลโก้บนหลังคาร้าน (ตัดจากแผนที่ตลาด) |
| `photos/` | รูปจริงจากเว็บตลาด (ย่อแล้ว) + ภาพจัดล็อก `lot-*.jpg` |
| `blender/` | สคริปต์ Blender: ชุดไทย · ภาพจัดล็อก · ภาพ 4K ทั้งตลาด |
| `ข้อมูลมาขาย-จากเว็บ.md` | ข้อมูลที่ดึงจากเว็บตลาด + จุดที่ยังขัดกัน (⚠️) |
| `สถานะงาน.md` | ทำอะไรไปแล้ว · รอใครตอบอะไร |

ข้อมูลที่มี `?` ในหน้าเว็บ = ยังรอยืนยันกับสำนักงานตลาด
