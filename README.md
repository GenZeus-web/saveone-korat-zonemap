# ผังโซนตลาดเซฟวัน โคราช (ร่าง)

หน้าเว็บสำหรับผู้ค้า: แตะโซนบนผัง 3 มิติ ดูว่าขายอะไรได้ ราคา วิธีจอง และรูปจริง · ออกแบบให้มือถือเป็นหลัก

## เปิดดู

- **ไฟล์เดียว:** ดับเบิลคลิก `ผังโซนโคราช-ไฟล์เดียว.html` (ฝังโมเดล/รูปไว้ในไฟล์ · ส่งต่อได้)
- **ตัวแก้:** `python -m http.server 8790` ในโฟลเดอร์นี้ แล้วเปิด `http://localhost:8790/ผังโซนโคราช.html`

## แก้เนื้อหา (ข้อความ · ราคา · ไอคอน · รูป)

เปิด `…/saveone-korat-zonemap/admin` → เข้าระบบด้วยกุญแจ GitHub ของตัวเอง → แก้ → 💾 บันทึก (เว็บเปลี่ยนใน ~1–2 นาที)

- ไม่ต้องมีเซิร์ฟเวอร์ — หน้าแอดมินบันทึกลง repo ผ่าน GitHub API · ทุกการแก้เป็น commit (ดูได้ว่าใครแก้อะไร ย้อนได้)
- พนักงานแต่ละคน: บัญชี GitHub ที่เจ้าของเชิญเป็น collaborator + กุญแจของตัวเอง (classic token ติ๊ก `repo`) · ไม่มีกุญแจกลาง
- 👁 ดูตัวอย่าง = เปิดหน้าเว็บพร้อมที่แก้ (`?preview`) ก่อนบันทึก · ร่างเก็บในเบราว์เซอร์เครื่องนั้น
- รูปที่อัปถูกย่อในเครื่อง (ด้านยาว 1200 px) และได้ชื่อใหม่ `photos/u-*.jpg` เสมอ
- ในข้อความ: `[ข้อความ]` = ตัวเล็กสีเทา · ขึ้นบรรทัดใหม่ได้

## แก้โค้ด/ผังแล้วต้องทำ

1. แก้ `ผังโซนโคราช.html` (ผัง · ตรรกะ) หรือ `content.js` (เนื้อหา — ปกติแก้ผ่านแอดมิน)
2. `python build-assets.py` → สร้าง `assets.js` + `ผังโซนโคราช-ไฟล์เดียว.html` ใหม่
   (ไฟล์เดียวฝังเนื้อหา ณ ตอน build — แก้ผ่านแอดมินแล้วไฟล์เดียวไม่ตาม จนกว่าจะ build ใหม่)

## โครงสร้าง

| ที่ | อะไร |
|---|---|
| `ผังโซนโคราช.html` | หน้าเว็บ: ผัง 3 มิติ + วิธีแสดงผล |
| `content.js` | เนื้อหาทั้งหมด (ข้อความ ราคา ไอคอน รายการรูป) — หน้าแอดมินเขียนไฟล์นี้ |
| `admin/` | หน้าแอดมิน (เปิดด้วย `/admin`) |
| `models/` | โมเดล 3 มิติ (Kenney.nl CC0 + ชุดไทยที่สร้างเองใน `models/blender/`) |
| `logos/` | โลโก้บนหลังคาร้าน (ตัดจากแผนที่ตลาด) |
| `photos/` | รูปจริงจากเว็บตลาด (ย่อแล้ว) + ภาพจัดล็อก `lot-*.jpg` |
| `blender/` | สคริปต์ Blender: ชุดไทย · ภาพจัดล็อก · ภาพ 4K ทั้งตลาด |
| `docs/` | ลอจิก · ข้อมูลจากเว็บตลาด · สถานะงาน · อ้างอิงสาขากรุงเทพ (ดู `CLAUDE.md`) |

ข้อมูลที่มี `?` ในหน้าเว็บ = ยังรอยืนยันกับสำนักงานตลาด
